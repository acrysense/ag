# День рождения: метка и салют

В свой день рождения сотрудник видит в профиле («Моя страница») метку «С днём рождения!» и
салют (конфетти и шары). Пример — `dist/profile-birthday.html`, шаблон — `components/Celebration`.

В блоке профиля, между строкой с ФИО и строками «должность / аптека / телефон»:

```html
<button class="celebration profile__celebration" type="button" data-module="Celebration"
  data-path="components" data-celebration-key="ID сотрудника">… С днём рождения! …</button>
```

Разметку целиком — из `dist/profile-birthday.html` (значок и подпись для скринридера внутри).

- Выводить тем же сотрудникам и по той же дате, что и в блоке «День рождения» на сайте; в
  остальные дни — ничего.
- `data-celebration-key` — постоянный ID сотрудника: по нему салют сам запускается раз в день,
  повтор — нажатием на метку.
- Если страница кэшируется, признак «сегодня день рождения» считать вне кэша.
