# Конкурс со шкалами («О! МЕГАтур»)

Шаблон: `app/components/sections/contest/Contest/Contest.html`. Страница: `contest.html`, без
данных — `contest-empty.html`.

## Что выводит бэк

| В разметке | Откуда |
| --- | --- |
| Название конкурса | админка |
| «Период проведения конкурса:» | вёрстка |
| Даты периода | 1С: `StartPromotion` первого шага — `FinishPromotion` последнего |
| Шаг: «Шаг N», название | `PromotionName`, порядок — как в `Promotion` |
| Шаг: текст условия под названием | админка (по шагу) |
| Шаг: `data-plan` | `MaxThreshold` |
| Шаг: `data-fact` | `Threshold` из `PromotionFact` с тем же `PromotionName`; записи нет — `0` |
| «Факт по бренду ЛВ с НДС» | `ProductTurnoverFull` как есть |
| «Факт по бренду ЛВ без НДС» | `ProductTurnover` как есть |

`data-plan` и `data-fact` — числа как пришли из 1С (до 4 знаков, точка или запятая). Округлять
не нужно.

Ответ 1С пустой или ошибка — вместо всего блока `.contest` выводится заглушка «Нет данных для
отображения» (`NO DATA`, см. `SYSTEM-PAGES.md`), та же, что в «Мотивации». То же на странице
«Конкурсы».

## Что делает скрипт

Шкалу, рыбку, облачко, «Выполнено X из Y уп.», «Осталось Z уп.», «Цель достигнута» и
«1 деление = N уп.» строит `Contest.js` по `data-plan` и `data-fact`. В разметке для них только
пустые `[data-contest-scale]` и `[data-contest-summary]`.

- Цена деления: план ≤ 20 → 1 уп., ≤ 50 → 2, ≤ 125 → 5, больше → 10. Подписи — у каждого
  деления при цене 1, иначе каждые 5 делений.
- Заливка пропорциональная: деление i заполнено на `clamp(факт / цена − i, 0…1)`.
- Числа — до 2 знаков, без «,00», через запятую: `4.5732` → «4,57», `12` → «12», `18.5` → «18,50».
- Факт (после округления) ≥ плана — цель достигнута. Больше на странице ничего не меняется.
- Цвет шага — по порядку: нечётный бирюзовый, чётный оранжевый.
