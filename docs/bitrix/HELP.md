# Помощь (база знаний CRM и ЛК)

Раздел «Помощь»: главная, страница раздела и блок «Вопросы по странице» внутри разделов CRM/ЛК.
Страница статьи — отдельно, позже.

Демо: `help.html`, `help-section.html`, `tasks.html` (блок справа или под списком). Витрина —
группа «Помощь». Шаблоны — `app/components/sections/help/`, данные демо — `app/pages/help*.page.json`.

Стили и скрипты включаются только своими классами и `data-module` — на текущие страницы не влияют,
пока бэк не выведет новую разметку.

## Страницы

Обёртка — как у остальных страниц ЛК, внутри `wrapper__main`:

```html
<div class="wrapper__wide">
  <div class="help-page">
    <!-- крошки: components/Breadcrumbs, class="help-page__crumbs" -->
    <!-- главная: HelpHero, HelpCategories, затем -->
    <div class="help-page__row">
      <!-- HelpFaq -->
      <div class="help-page__side"><!-- HelpUpdates, HelpSupport --></div>
    </div>
    <!-- раздел: -->
    <div class="help-page__layout">
      <!-- HelpNav -->
      <div class="help-page__main"><!-- HelpSection, HelpFaq --></div>
    </div>
  </div>
</div>
```

## Блоки и поля

Все тексты и ссылки — поля инфоблока, в вёрстке ничего не зашито. Пустой список — блок не выводится.

- **HelpHero** — заголовок, описание, поиск (ниже), «Часто ищут»: подпись и ссылки
  (текст + ссылка на результаты поиска с этим запросом).
- **HelpCategories** — разделы: значок (имя иконки спрайта, например `erp-tasks`, `site-home`),
  название, «N статей» (склонение — на бэке), описание, до 3 статей (текст + ссылка), ссылка
  на раздел.
- **HelpFaq** — «Частые вопросы»: вопрос, ответ (простой текст), ссылка на статью. `open` —
  вопрос раскрыт при загрузке (обычно первый). Раскрываются без скрипта (`<details>`).
- **HelpUpdates** — «Новое в базе знаний»: дата (`datetime` и подпись «18 сентября»), название,
  ссылка.
- **HelpSupport** — «Не нашли ответ?»: текст, кнопка (ссылка на форму или `mailto:`), телефон.
- **HelpNav** — навигация: заголовок («Помощь по CRM»), разделы (название, ссылка). У текущего
  раздела — класс `is-open` у ссылки и список его статей; текущая статья — `aria-current="page"`.
  Статьи остальных разделов не выводить.
- **HelpSection** — заголовок раздела (`h1`), «N статей», описание, статьи: название, пояснение,
  ссылка. Нет статей — текст «В этом разделе пока нет статей».
- **HelpInline** — «Вопросы по странице» (ниже).

## Поиск по Помощи

Обычная форма `GET` на страницу результатов общего поиска портала, раздел «Помощь». Без скрипта
тоже работает. Скрытые поля — `section=help` и `where=crm` (из ЛК — `where=lk`).

Подсказки — `data-suggest-url` у формы. Запрос: `GET <url>?q=…&section=help&where=crm`, со 2-го
символа, через 300 мс после ввода. Ответ:

```json
{
  "count": 18,
  "items": [
    { "type": "article",  "titleHtml": "Создать <mark>задач</mark>у", "meta": "Статья · Задачи", "url": "/help/tasks/create/" },
    { "type": "question", "titleHtml": "Как назначить <mark>задач</mark>у нескольким?", "meta": "Вопрос · Задачи", "url": "/help/tasks/#faq-3" },
    { "type": "section",  "titleHtml": "Создать <mark>задач</mark>у → Статусы", "meta": "Раздел статьи · Задачи", "url": "/help/tasks/create/#statuses" }
  ]
}
```

- `type`: `article` — статья, `question` — вопрос FAQ, `section` — раздел внутри статьи (ссылка
  с якорем). Выводится до 5 подсказок.
- `titleHtml` — название, совпадение в `<mark>`; другие теги выводятся как текст. Вместо
  `titleHtml` можно отдать `title` — простой текст без подсветки.
- `count` — сколько всего результатов: кнопка «Все результаты в Помощи · N» (отправляет форму).
- Пустой `items` — «В Помощи пока нет ответа на этот вопрос». Ошибка сервера — окно не
  открывается, Enter ведёт на страницу результатов.

## Вопросы по странице (HelpInline)

Блок с ответами из Помощи на странице раздела CRM/ЛК. Вид — по ширине самого блока: в колонке
до 600 — узкий, шире — широкий. Стрелка сворачивает блок до шапки с числом вопросов; выбор
запоминается в браузере (`localStorage`, ключ `ag:help-inline:<id блока>`) — `id` у разных
разделов должен быть разным (`help-tasks`, `help-visits`…).

Поля: заголовок, подпись (видна в широком), вопросы (как у HelpFaq; подпись ссылки — «Подробнее
в разделе «Помощь»»), «Все статьи» (ссылка на раздел Помощи), «Не нашли ответ?» (ссылка на
поддержку, видна в широком).

На странице задач блок идёт после вкладок внутри `wrapper__narrow`, у обёртки — класс
`wrapper__narrow--aside`:

```html
<div class="wrapper__narrow wrapper__narrow--aside">
  <!-- … вкладки задач, как сейчас … -->
  <section class="help-inline" id="help-tasks" data-module="HelpInline" data-path="sections/help">…</section>
</div>
```

С 1600 блок — колонка 350 справа от списка, уже — под списком. Без класса и блока страница
задач такая же, как сейчас.
