# Поиск в шапке ЛК: раздел страницы CRM

Поиск в шапке ЛК — тот же, что на сайте (`layouts/SiteSearch`): разделы Справочник, Новости,
Документы, Вакансии ищут через модуль поиска. На странице CRM (Сотрудники аптек, Аптеки,
Менеджеры, Визиты, Задачи) в поиске есть ещё один раздел — раздел **этой страницы**. Он не ищет,
а фильтрует список на странице, как раньше фильтр в шапке.

## Что выводит бэк

1. **Разделы.** Разделы сайта — на всех страницах. Раздел CRM — только на его странице, другие
   страницы CRM в поиске не выводятся. На странице CRM её раздел отмечен (`checked`):

   ```html
   <label class="site-search__section">
     <input class="site-search__radio" type="radio" name="section" value="crm-employees" checked
            data-label="Сотрудники" data-where="в Сотрудниках" data-action="/crm/employees/" />
     …значок…
     <span>Сотрудники</span>
   </label>
   ```

   `data-action` — адрес этой же страницы: по нему скрипт понимает, что раздел — фильтр списка.
   Название раздела — без «CRM» («Сотрудники», «Аптеки», «Менеджеры», «Визиты», «Задачи»).

2. **Поле поиска по списку** — первым в фильтрах раздела (и в ответе `filtersUrl`):

   ```html
   <div class="search-filter search-filter--wide search-filter--text">
     <input class="search-filter__input" type="text" name="q" value="" placeholder="ФИО"
            aria-label="ФИО" autocomplete="off" enterkeyhint="search" />
   </div>
   ```

   Подпись — по списку («ФИО» у сотрудников и менеджеров, «Найти» у остальных). `name="q"` —
   тот же запрос, что раньше вводили в шапке: ищет по всем колонкам строки, в серверном режиме
   таблицы уходит параметром `q` (README.md, раздел 5).

3. **Остальные фильтры** раздела — как сейчас (ключи совпадают с `filterKey` колонок,
   TABLES.md, «Фильтры из шапки сайта»).

4. Необязательно: подсказка в поле шапки, пока выбран раздел страницы, — атрибут
   `data-page-placeholder` у `.site-search__input` (по умолчанию «Поиск — в фильтрах раздела»).

## Как работает

- Выбран раздел страницы — поле в шапке ввод не принимает (набранное попадает в поле «ФИО»),
  подсказки модуля поиска не запрашиваются.
- «ФИО» фильтрует список сразу при вводе; остальные фильтры — по «Применить»; «Сбросить все» —
  сразу. Выбор — в адресе страницы (`?q=…&region[]=…`), над списком — плашки фильтров.
- Выбрали другой раздел (например, Вакансии) — поле в шапке снова ищет через модуль поиска.

## Совместимость

Без поля `q` в фильтрах (текущая разметка) раздел страницы работает как прежде: запрос
вводится в шапке и применяется к списку кнопкой внизу окна. Новое поведение включается, когда бэк
выведет поле `q` в фильтрах раздела.
